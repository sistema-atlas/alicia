# Portal do cliente

O portal é o endereço onde alunos e membros entram para ver cursos e comunidade. Fonte: tela real da conta Atlas em 05/10/2026 (`docs/navegacao-crm/sites-e-funis.md`).

## O que o cliente costuma pedir

| Pedido | Onde |
| --- | --- |
| "Qual é o link do portal?" | Portal do cliente > Painel, campo do endereço com botão de copiar |
| "Manda o acesso para o aluno" | Painel > Convidar ou Enviar e-mail de login (`CONFIRMO ENVIO`) |
| "Quero um link que entra sem senha" | Painel > Gerar link mágico. O link é pessoal; entregue só ao cliente |
| "Muda as cores e o logo" | Configurações > Identidade visual. Use a marca da conta (`get-design-kit`, skill `atlas-conta-e-equipe`) |
| "Quero o portal no meu domínio" | Configurações > Configuração de domínio. Precisa de DNS: passo a passo e aprovação reforçada (`CONFIRMO PUBLICAÇÃO`) |
| "Portal em português" | Configurações > Configurações de idioma |
| "Lembrete por e-mail para os membros" | Configurações > Configurações de e-mail |
| "Quero app com a minha marca" | Branded Mobile App. Avise que é um projeto à parte; passe para a Atlas se o cliente quiser seguir |

## Cuidados

- O aviso de novo layout tem **Ative para todos**: nunca clicar. Use **Talvez mais tarde** ou **Abrir prévia**.
- Contadores de Convidados e Usuários são da tela. Não compare com `list-enrollments`, que conta outra coisa.
- Depois de mudar identidade ou idioma, abra o portal numa aba anônima e no celular para conferir.
