# Alicia, assistente da Atlas

A Alicia é a assistente da Atlas dentro do seu Claude ou do seu Codex. Você conversa em português e ela faz na sua conta do Atlas CRM: contatos, funis, campos, formulários, sites, automações, conversas, agenda, agentes de IA, rastreamento, relatórios e mais.

Toda alteração aparece antes para você aprovar. Envio de mensagem, exclusão, cobrança e publicação pedem uma confirmação escrita a mais.

## O que você precisa

- Uma conta ativa no Atlas CRM e o seu login.
- Claude (web, app de computador ou Claude Code) ou Codex.
- No Claude web e no app: execução de código ligada em Configurações > Recursos.
- Para tarefas feitas na tela do CRM (painéis, formulários, páginas): a extensão **Claude in Chrome**, com o Atlas CRM aberto e logado no Chrome. No Codex, essas tarefas viram um passo a passo para você seguir.

## Instalar no Claude (web ou app)

1. Abra **Personalizar > Plugins**.
2. Clique em adicionar marketplace e cole: `sistema-atlas/alicia`
3. Instale o plugin **assistente-atlas** (Alicia, assistente da Atlas).
4. Na aba **Conectores** do plugin, conecte o **Atlas CRM** e faça login com o seu usuário do CRM. A tela de login pode mostrar o nome do provedor da plataforma: é o login oficial, pode seguir.
5. Escolha a sua conta (empresa) e aceite as permissões.
6. Abra uma conversa nova e diga: **Oi, Alicia**.

## Instalar no Claude Code

```
claude plugin marketplace add sistema-atlas/alicia
claude plugin install assistente-atlas@atlas
```

Na primeira vez que a Alicia usar o CRM, o Claude Code abre o login do conector.

## Instalar no Codex

```
codex plugin marketplace add sistema-atlas/alicia
codex plugin add assistente-atlas@atlas
```

Na primeira vez que a Alicia usar o CRM, o Codex pede o login do conector Atlas CRM. Se o login não aparecer, fale com o suporte da Atlas.

## O que dá para pedir

- "Faz um raio-x da minha conta."
- "Cria um campo de data de nascimento nos contatos."
- "Move para Ganho todas as oportunidades do João que fecharam ontem."
- "Por que esse lead não entrou na automação de boas-vindas?"
- "Monta um formulário de orçamento com a minha marca."
- "Como foi o meu mês: leads por origem, vendas e conversão."
- "Quero captar leads de um anúncio e que eles caiam no meu funil."
